# 个人阅读知识中枢:MVP 整合版

> 整合自两份设计:**「深度拆书 + Skill 沉淀」**(深度)与 **「书影式聚合 + 碎片化回顾」**(轻量)。
> 核心逻辑:用 AI 把书**拆透**,用卡片把知识**盘活**,让阅读资产产生复利。小红书只是输出模板之一。

---

## 一、产品定位

- **原定位**:把微信读书笔记变成小红书文案和 Skill 的桌面端工具。
- **新定位**:一个既能**深度拆解**书籍内核,又能**碎片化回顾**知识卡片的**个人阅读知识中枢**。
- **解决的两个痛点**:
  - 划线后不回顾(轻量回顾层解决)
  - 读完不会用(深度拆书 + Skill 沉淀解决)
- **双轮驱动**:深度拆解(壁垒) + 轻量回顾(留存)。

---

## 二、整体布局与交互框架

桌面端采用三栏布局,发挥**多窗口对照**和**大空间操作**的优势。

- **左侧导航栏(约 20%)**:回顾首页、书架、拆书历史、Skill 库,支持搜索与标签筛选。
- **中间内容区(约 50%)**:核心工作区,展示原文划线、AI 拆解结果。
- **右侧操作区(约 30%)**:Skill 卡片、笔记编辑器、导出与预览。
- **顶部工具栏**:全局搜索、设置、数据源配置入口、"开始拆解"按钮。

**默认首页为"漫游与回顾"视图**(见模块 3),点击卡片可进入全屏深度拆解工作台,实现"碎片浏览 → 深度阅读"的无缝切换。

---

## 三、核心功能模块

### 1. 数据导入与同步

目标:交互最简单、摩擦最小。

- **微信读书同步**:配置后左侧自动展示书架,支持"最近阅读 / 全部书籍"筛选,点击书籍加载其划线与想法。
- **配置引导**:首次启动弹出图文引导,提供"测试连接"按钮,验证成功后进入主界面。凭证**仅保存在本地**,界面明确提示"本地加密存储、不上传云端"。
- **本地文件导入**:支持拖拽 Markdown、PDF、EPUB 文件,自动解析后进入拆书流程,作为不接 API 时的替代方案。
- **上下文识别**:同步时自动识别笔记所在章节与上下文,为后续 AI 拆解做准备。
- **多平台笔记(后续迭代)**:掌阅、得到等平台的划线导入,MVP 阶段不做。

### 2. AI 深度拆书工作台(核心壁垒)

用户停留时间最长的页面,围绕"深度阅读 + 结构化拆解"。

- **双栏对照视图**:左侧原文与划线,右侧 AI 拆解结果,两栏宽度可拖拽调整。
- **一键拆解**:分析当前书籍全部划线笔记,生成结构化报告。
- **拆解维度**(均以**可折叠卡片**呈现,而非纯文本):
  - **全书总揽**:一句话核心思想、3-5 个核心论点,用金字塔原理梳理支撑论据。
  - **章节地图**:按章节梳理逻辑结构,标注最具价值章节。
  - **模型与框架**:识别书中思维模型,用可视化卡片展示,可导出 Mermaid 图表 / 思维导图。
  - **案例与故事库**:用 STAR 法则整理核心案例,便于写作调用。
  - **术语表**:提取术语与定义,生成可检索的术语卡片。
- **原文定位回溯(信任关键)**:点击任意 AI 观点(或卡片上的"引用"图标),左侧高亮对应原文划线,确保"拆书不瞎编"。
- **手动补充笔记**:用户在拆解结果旁添加自己的理解,系统自动融合人工笔记与 AI 内容。

### 3. 每日回顾与随机漫游(轻量留存层)

- **回顾页卡片墙**:每天新增的划线与拆解出的 Skill 卡片,以精美卡片形式排列,支持按书籍、标签筛选。
- **随机漫游**:随机抽取卡片做碎片化复习。
- **"深度思考"入口**:漫游卡片上可一键展开完整 AI 拆解报告与原文定位。

### 4. Skill 沉淀与卡片库

把书里的方法论变成可反复调用的"技能"。

- **Skill 生成**:拆解完成后自动识别可执行方法论,生成卡片,包含:技能名称、适用场景、核心步骤、判断标准、原文出处。
- **卡片化管理**:左侧"Skill 库"以网格展示,支持按标签、书籍、类型筛选。
- **编辑与完善**:用户补充使用经验、修改步骤、添加关联笔记。
- **关联与回溯**:每张卡片标注来源书籍与原文位置,可跳转回拆解页。
- **导出与复用**:支持导出 Markdown、JSON,便于导入 Notion / Obsidian,或供其他 AI Agent 调用。

### 5. 多场景输出与分享

小红书只是其中一种模板。点击"导出 / 分享"弹出模板选择器:

- **小红书笔记文案**:带情绪钩子的标题、Emoji 分段正文、话题标签。
- **书摘 / 知识卡片海报**:高颜值卡片图,方便分享。
- **阅读统计海报**:月度 / 年度阅读统计。
- **深度听书稿**:类似得到风格的口语化讲书稿。
- **思维导图大纲**:导出 Markdown 大纲,可导入 XMind。
- **记忆卡片**:核心论点、框架、金句做成可打印卡片。
- **Obsidian 兼容 Markdown**:结构化导出,便于长期沉淀。
- **一键复制 / 导出文件**:生成后可复制到剪贴板或导出为 Markdown,导出前支持**预览模式**。

---

## 四、关键交互细节

- **拖拽**:原文划线可拖到右侧笔记编辑器或"Skill 编辑区",自动生成引用标注并关联上下文。
- **快捷键**:`Ctrl/Cmd + D` 快速拆解、`Ctrl/Cmd + S` 保存当前状态,并支持常用复制等操作。
- **状态提示**:拆解过程显示进度条和加载动画,避免用户误以为卡死。
- **本地优先**:API 凭证、笔记、拆解结果、Skill 卡片全部存本地;关闭后重开状态完整恢复;支持**一键导出完整数据备份**。
- **空状态引导**:无书籍或 Skill 时,引导"添加第一本书"或"配置数据源"。

## 五、与竞品(书影)的差异化

| 维度 | 书影(竞品) | 本产品(融合版) |
|---|---|---|
| 核心定位 | 笔记聚合与碎片化回顾工具 | 深度拆书与知识资产化引擎 |
| 内容深度 | 展示原文划线和简单想法 | AI 结构化拆解、提取思维模型、沉淀 Skill |
| 使用场景 | 移动端碎片刷卡片、看统计 | 桌面端深度拆解 + 卡片回顾 |
| 知识复用 | 回顾与简单分享 | 导出为 Markdown / Skill,供其他 AI 调用 |
| 输出能力 | 统计海报、书摘卡片 | 小红书文案、思维导图、听书稿、海报 |

## 六、MVP 功能边界(必须克制)

**MVP 阶段不做:**

- **用户账号系统**:不注册登录,数据全部本地。
- **多端云同步**:先做单端桌面版。回顾 / 漫游功能先在桌面端内实现,**移动端碎片回顾放到后续迭代**。
- **社区与 Skill 市场**:先让个人用户用起来。
- **付费墙**:MVP 阶段免费开放,先验证用户价值。
- **自动发布到小红书**:平台不开放个人 API 且有违规风险,只做"生成并导出"。
- **多平台笔记导入**:先只做微信读书与本地文件。

## 七、核心用户流程

1. 打开 App → 配置数据源(凭证仅本地保存)。
2. 左侧书架同步,默认进入"每日回顾 / 随机漫游"首页。
3. 选择一本书,查看划线笔记,点击"开始拆解"。
4. AI 生成结构化拆解报告,用户对照原文阅读并补充笔记。
5. AI 识别并生成 Skill 卡片,用户编辑后存入 Skill 库,同时进入回顾卡片池。
6. 日常通过"回顾 / 漫游"碎片复习,需要时点"深度思考"回到完整拆解。
7. 点击"导出 / 分享",选择模板(小红书文案、海报、导图等),复制或导出文件。

---

## 八、风险与合规提醒

- **版权红线**:只基于用户**自己划线的笔记**或用户自己上传的文件做拆解;不提供整本书全文展示或下载;公开分享内容以摘要、观点为主,避免大段原文。
- **数据源可行性(需先核实)**:微信读书是否有稳定、合规的官方 API 尚不明确,需在开发前确认可行方案;若无,退而采用用户手动导出笔记 / 本地文件导入。不建议用违反平台条款的抓取方式。
- **凭证安全**:任何 API Key / 登录凭证只保存在用户本地,绝不上传服务器。
- **AI 幻觉**:"原文定位回溯"是核心卖点,上线前需抽样验证锚点准确率。
- **成本控制**:整本书处理成本较高;基于划线笔记而非全书文本,可显著降低 token 消耗。
- **小红书规则**:定位为"辅助创作",避免被判定为批量营销工具。

---

## 九、总结

这个整合版保留了书影"轻量、美观、易回顾"的体验,同时发挥"AI 深度拆解、Skill 沉淀"的壁垒。用户既能把书里的知识**拆透**,也能在碎片时间**刷到**它,最后还能**导出**成内容或知识资产。
